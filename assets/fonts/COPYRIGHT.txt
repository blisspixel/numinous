Bundled study font copyright notices

The App embeds three unmodified font files. Native release archives include
this notice, the source and SHA-256 inventory in README.md, and the original
license texts listed below. The font files are not duplicated as external
assets in those archives.

table (name ID 0). The original license files retain their own notices too.
