## The mathematical question

Every graph allegedly admits an edge partition into only linearly many simple cycles and single edges.

## Visual and sonic possibility

Colored loops disentangle the graph; cycle lengths may map to rhythmic phrases.

## What makes it hard

The universal constant is unspecified, and a found decomposition need not be minimum. Simple cycles cannot repeat vertices; preserving edge ownership avoids mistaking an overlapping cycle cover for a partition.

## Inside the construction

### construction

Pair vertices inside designated sets, remove loops and duplicate quotient edges, and retain one original representative per quotient edge.

- **Source locator:** lem:pair-folding
- **Numinous use:** Fold a graph and track discarded edges.
- **Limit:** Neighbor counts into each folding set must be bounded at every vertex.

### invariant

Lifting a quotient cycle needs reserved connecting paths with disjoint interiors avoiding representative endpoints.

- **Source locator:** sec:folding
- **Numinous use:** Unfold a cycle and detect self-intersections.
- **Limit:** A degree bound only at paired vertices is insufficient, as complete bipartite examples show.
