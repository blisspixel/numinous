## Inside the construction

### algorithm

Ordered extraction sorts source right endpoints, moves boxes into private remote columns, rescales there and delivers in target order, producing rational swept-box clearances.

- **Source locator:** bc:ordered-proof
- **Numinous use:** Implement a finite collision-free route planner with a replayable clearance witness.
- **Limit:** The negative-height guarantee is for the coded central plane, not every point of the solid box.

### path guarantee

Simultaneous lifting uses reciprocal interpolation whose first coordinate remains a convex combination of its endpoint coordinates at every time.

- **Source locator:** bc:simultaneous
- **Numinous use:** Provide a simple checked observer-exclusion certificate for an entire transition.
- **Limit:** The specified grid, scale factors and padding bounds are part of this primitive.
