## Inside the construction

### algorithm

A q-degenerate graph is list-colorable from lists of size q+1 by reversing a low-degree deletion order.

- **Source locator:** list:elementary
- **Numinous use:** Remove vertices and replay greedy coloring.
- **Limit:** This is a sufficient condition, not an exact list-chromatic algorithm.

### invariant

Precoloring a deleted set of size z removes at most z colors from each remaining list, yielding an additive deletion bound.

- **Source locator:** list:elementary
- **Numinous use:** Track palette loss as a separator is colored.
- **Limit:** The linear Hadwiger-number bound needs further extraction and routing.
