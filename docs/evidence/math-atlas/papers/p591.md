## The mathematical question

Approximation-paving controls compressed operators relative to a maximal abelian subalgebra.

## Visual and sonic possibility

Proposed visual: Paint indices of a zero-diagonal self-adjoint matrix into groups and watch compressed block norms shrink. No physical sound model is claimed.

## What makes it hard

The general theorem permits strong-limit approximants and a MASA subtraction; raw block norm of an arbitrary matrix is the wrong target. Enumerating colorings scales exponentially; symbolic formulas need bounded input sizes. The theorem norm-paves a nearby bounded approximant and gives a sixth-power bound for arbitrary MASAs, not quadratic norm paving of the original operator.

## Inside the construction

### exact-polynomial

For independently colored vertices, the expected characteristic polynomial of the retained same-color matrix has a determinant-derivative formula; deleting a vertex differentiates its multiaffine variable.

- **Source locator:** poly:definition; poly:deletion; poly:differential-formula
- **Numinous use:** Build a matrix-coloring instrument with exact small expected polynomials and linked roots.
- **Limit:** Enumerating colorings scales exponentially; symbolic formulas need bounded input sizes.

### combinatorial-witness

Each permutation cycle survives only when all its vertices share one color, with weight sum_i product_v t_vi; disjoint cycles use independent choices.

- **Source locator:** poly:cycle-weight
- **Numinous use:** Expose root changes through cycle contributions and freely editable color probabilities.
- **Limit:** The theorem norm-paves a nearby bounded approximant and gives a sixth-power bound for arbitrary MASAs, not quadratic norm paving of the original operator.
