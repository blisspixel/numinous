## Inside the construction

### representation

Blocks are lists of overlapping windows; random partitions of embedded shorter windows produce count histograms.

- **Source locator:** upper:section
- **Numinous use:** Let users explore multiscale substring histograms on the same editable strings.
- **Limit:** A single sampled partition is not the deterministic embedding.

### derandomization

Averaging over all partition outcomes defines a deterministic ell1 map; insertion-deletion moves pair most shifted windows identically.

- **Source locator:** upper:section
- **Numinous use:** Compare sampled feature approximations with exact small outcome averages.
- **Limit:** The theorem's dimension and constants need not yield a practical full enumeration.
