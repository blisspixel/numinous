## The mathematical question

The centered disk maximal operator is claimed to control total gradient at the W-one-one endpoint.

## Visual and sonic possibility

## What makes it hard

The operator averages absolute values and uses disks centered at the evaluation point. Finite-radius pixel maxima do not certify the continuum inequality.

## Inside the construction

### bounded-operator

With a positive lower radius a, the disk-average envelope over [a,b] is finite everywhere and has a Lipschitz bound proportional to ||grad g||_1/(pi a^2).

- **Source locator:** lem:sobolev-band; eq:band-lipschitz
- **Numinous use:** A disk-sweep tool can show which radius attains the current sampled envelope and how the lower-radius cutoff changes stability.
- **Limit:** A finite radius grid approximates the continuous supremum; supplied smooth-input assumptions must be distinguished from raw image pixels.

### error-bound

Changing the input changes the bounded-radius envelope by at most its L1 input error divided by pi a^2.

- **Source locator:** eq:band-uniform-approximation
- **Numinous use:** Attach a conservative approximation budget to image/field envelope comparisons.
- **Limit:** Removing the lower-radius cutoff makes this simple bound deteriorate; it does not itself prove the global endpoint gradient theorem.
