## What makes it hard

An oracle result is not an efficient real-world synthesis algorithm. A whole exponentially tabulated multiplexor counts as one slot in this model. The theorem allows an unrestricted Boolean oracle truth table; it is not an efficient classical encoding of arbitrary unitaries.

## Inside the construction

### construction

Prefix probabilities P(p) give binary rotations with amplitudes sqrt(P(p0)/P(p)) and sqrt(P(p1)/P(p)); a final diagonal supplies phases.

- **Source locator:** slot:preparation
- **Numinous use:** Make an amplitude tree whose branch widths and phases jointly paint a quantum state.
- **Limit:** A whole exponentially tabulated multiplexor counts as one slot in this model.

### error-contract

Clean error is an operator norm bound on the embedded input, preserving coherent labels and restoring work registers without quotienting label-dependent phases.

- **Source locator:** slot:clean-error
