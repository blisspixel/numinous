## The mathematical question

Graph identification asks whether refinement distinguishes one graph from every nonisomorphic competitor, with claimed EXPTIME-completeness for input dimension.

## Visual and sonic possibility

Matched color histograms highlight surviving ambiguity; refinement events can trigger mapped tones.

## What makes it hard

Testing finitely many competitors cannot certify identification against every graph. Variable dimension creates enormous tuple spaces, so this manuscript is chiefly a complexity lens, not a promise of an efficient classifier.
