## Inside the construction

### probability-mechanism

The argument first exposes selector choices, then identifies distinct terminal addresses. Only after that conditioning are the terminal bits treated as independent.

- **Source locator:** lem:fixed-scale
- **Numinous use:** Build an inspectable randomized routing toy where players reveal bits and see which independence claims remain justified.
- **Limit:** Unconditioned intuitive independence can fail when addresses are selected adaptively; the address ledger is part of the object.

### exact-finite-law

At one fixed scale the miss probability is (1-p/2)^((M-1)r), derived from distinct selector and terminal entries.

- **Source locator:** eq:fixed-scale-miss
- **Numinous use:** Compare exact tiny-table enumeration with seeded repeated trials and reveal the mechanism behind the failure rate.
- **Limit:** This fixed-scale calculation is only one part of excluding all scales and centers in the infinite construction.
