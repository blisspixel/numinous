# Named sliders

The original knob is `a`. A formula may name a few more.

These two small creations let you hear that. There is no score or required
order. A slider is a declared range, not a free real.

From a packaged install, open a capsule by id: `extra-knob`, `live-ratio`.
`plot_expression` with `list_experiments` true and `family` `named-sliders`
lists them. `open_creation` accepts those ids.

| Creation | Try this |
| --- | --- |
| [An extra knob](extra-knob.num) | Change `b`. What moved, and what stayed the same? |
| [A live ratio](live-ratio.num) | Change `p` or `q`. When does the path close again? |

The trial does not gate play.

<details>
<summary>The mathematics</summary>

`a` remains the unnamed default knob so every older capsule still opens.
Extra identifiers are sliders: a finite value inside a closed range. Capsules
write them on `NUMINOUS_STUDIO 6`. `cos(2*pi*p*t)` and `sin(2*pi*q*t)` with
integer `p` and `q` close after one unit of `t` when the ratio is rational
in lowest terms; the period is then 1. Returning home's four capsules are
four points on this pair of knobs.

</details>
