# Three readings

The same expression is three claims. Which claim you are making is part of
the artifact.

These four small creations let you compare a phase wheel, a pole, a proved
curve, and a height map of that same curve. There is no score or required
order. Height and phase sing along the real axis; the zero reading is a
proof and stays silent.

From a packaged install, open a capsule by id: `simple-zero`, `a-pole`,
`the-circle`, `the-bowl`. `plot_expression` with `list_experiments` true and
`family` `three-readings` lists them. `open_creation` accepts those ids.

| Creation | Try this |
| --- | --- |
| [A simple zero](simple-zero.num) | Follow the ramp around the origin. How many times does it go around before it meets itself? |
| [A pole](a-pole.num) | Compare its formula with A simple zero. Which way does the ramp run now? |
| [The circle](the-circle.num) | A marked cell is a proved crossing, not a sample. What is a blank cell entitled to claim? |
| [The bowl](the-bowl.num) | This is the same formula as The circle, read as height. Where does the bowl meet nothing? |

The bowl is a fork of The circle. Its capsule retains the exact parent
link. A picture is not a reading. The trial does not gate play.

<details>
<summary>The mathematics</summary>

Phase is where the value points. Height is how big it is. Zero is where it
is nothing. Tupper showed that a two-colour implicit plot is not computable
for an arbitrary formula, so Zero has a third answer: unresolved. A circle
that touches zero without crossing, `(x^2 + y^2 - 1)^2 = 0`, is the case a
sign test drops. A pole of `tan` is the case a sign test invents. The plate
refuses both lies.

</details>
