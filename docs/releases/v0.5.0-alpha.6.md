# Numinous 0.5.0 alpha 6

The Windows install, play, and uninstall roundtrip now protects its workspace
with the installer's own private-directory policy before the ancestor check
runs. A new directory under a profile can inherit replacement rights that the
profile itself exposes only as inherit-only rules. The check is unchanged and
still refuses a path another account can replace.

Flagship PNG reports include a fixed-grid luminance signature, and room-bed
reports include a normalized spectral fingerprint from the existing analyzer.
The golden gate compares both at the tolerances written in
`scripts/flagship-goldens.py` and still requires an exact PNG hash. The
designed diff classifier is not part of this gate, and the PNG plates were
not rebaselined.

Sensory Alpha remains active. Physical pacing receipts, the flash and
color-vision rulings, catalog-wide perceptual comparison, and further glow
stay open. This release does not claim the Sensory Lift is promoted.

- [Start playing](https://github.com/blisspixel/numinous/blob/v0.5.0-alpha.6/PLAY.md)
- [Verify a build](https://github.com/blisspixel/numinous/blob/v0.5.0-alpha.6/VERIFY.md)

For an installer-created installation, run `numinous update`. For a loose
archive, download a fresh platform archive. Player-owned state is retained by
the managed update path.
