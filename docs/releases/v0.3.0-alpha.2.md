# Numinous 0.3.0 alpha 2

This prerelease gives Kepler Areas a room-owned wager and corrects the room's
equal-time geometry.

Choose an ellipse, then call whether the body moves faster, slower, or the same
near the sun. The App and MCP face withhold the answer until the call or a
four-tuning observation path lands. Equal-time positions then arrive around
the selected orbit before the result names the relation and exact
perihelion-to-aphelion speed ratio. A circle honestly answers same because it
has no nearer side.

The underlying room now solves Kepler's equation at equal mean-anomaly
intervals. Its sectors therefore represent equal swept areas in equal times,
instead of approximating them with equal eccentric-anomaly intervals. The
terminal's shared deterministic call engine continues to reach the same room
and readout.

The agent hallway now exercises Kepler through real MCP stdio for five fixed
personas. It requires play-first discovery, a withheld wrong call, a typed
truth, a consolidated reveal, and equal-time evidence in the ASCII frame. This
is deterministic machine-path evidence, not participant or consciousness
evidence.

The architecture now pins the current agent interoperability boundary. Agent
Plugins 1.0.0 discovers the play skill and MCP doorway, MCP carries live play,
native Numinous records remain authoritative, Open Knowledge Format v0.2
carries player-approved knowledge outward, and Watch Agent projects only
consented public events. The local model playtest also documents its complete
zero-cost participant budget.

The release includes Linux, Windows, Intel macOS, and Apple Silicon packages,
the optional soundtrack archive, checksums, an SPDX SBOM, and provenance
attestations.
