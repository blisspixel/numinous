# Numinous 0.4.0 alpha 15

Formula Jam gets steps, wraps, clamps, and thresholds.

The Studio's scalar language was intentionally small, but its seven functions
left common visual ideas awkward or impossible to state. A stepped wave needed
`floor`. A repeating ramp needed `mod`. A safe window or threshold needed
`min` and `max`. Those were the next grammar rung named on the roadmap.

This release adds all four through the bounded core parser and evaluator:

```text
floor(value)
mod(value, divisor)
min(left, right)
max(left, right)
```

`mod` is Euclidean, so negative inputs wrap to a nonnegative finite remainder.
`min` and `max` preserve undefined input instead of silently replacing it with
the other argument. Pair calls require one comma and exactly two arguments.
When that shape is wrong, the parser names the expected separator or closing
parenthesis and its one-based source column.

## Four new things to remix

The curated Formula Jam bank grows from twelve recipes to sixteen:

```text
floor(3*sin(x))/3
mod(x + pi, 2*pi) - pi
min(max(x, -2), 2)
max(abs(x) - a, 0)
```

They make the new vocabulary visible without requiring anyone to read a
grammar first. They appear in App Random and Auto, the CLI recipe list, and MCP
recipe discovery. The App's dismissible help names both one-argument and
two-argument forms.

## One language through the whole loop

The App, CLI, and MCP faces still delegate parsing and evaluation to one core.
A formula with a comma can be plotted or sung, saved as `.num`, carried in an
encoded native link, reopened, and remixed. Focused tests cover the new numeric
semantics, arity errors, undefined values, curated bank, App help, CLI plot,
direct MCP response, capsule round trips, and a real MCP stdio session.

The expression source and token caps, recursion limit, deterministic recipe
walk, existing capsule format, and audio contract are unchanged. This release
does not add arbitrary code, a second variable, multi-expression capsules, or a
qualifying Understanding Alpha cohort result. Stable 0.4.0 still requires the
registered study and independent audit named in the roadmap.
