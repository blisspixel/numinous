# Numinous 0.4.0 alpha 29

See why a cheaper connection changes a shortest-path search.

## Search on the network

Route Lab draws its caller-paced calculation on the actual roads in ordinary
play and native authoring. Tentative predecessors, settled connections, and
the completed path have different marks. The latest improved road is emphasized.
Junction shapes and labels distinguish tentative, final, unseen, and unreachable
states without relying on color. Dense and compact editor maps retain a
junction inspector for the selected cost and predecessor. Click a node or use
the junction controls to inspect it without advancing or restarting search.

Step backward to revisit an earlier decision. Its later costs and connections
disappear. Edits clear the old calculation. An unseen junction is marked
unreachable only after the source search completes, and the final path appears
only at completion.

## The same revealed state across three faces

Core owns the revealed-prefix projection. Plain CLI output reports junction
states, cumulative costs, and predecessors. MCP adds `trace.view` beside the
existing events and final result. Followable next calls and working snapshots
retain their existing shape; portable route identities and kept questions
remain compatible.

The screenshot matrix covers initialization, cheaper predecessor replacement,
backward stepping, disconnected completion, and dense networks at the supported
window sizes. These are functional and rendering checks; participant
comprehension has not been measured. Understanding Alpha remains active, with
its exit awaiting the registered study.
