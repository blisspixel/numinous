# Numinous 0.4.0 alpha 21

Two corrections from an external agentic playtest of the alpha 20 packages.
Both were reported by a tester playing the published archives without reading
source, and both are the kind of defect only a player finds.

## An unwritten depth says where the depth is written

Asking a room for a Mathematics treatment it does not have used to answer only
that this room does not have one. That is true, and it reads as a broken
feature. It also left one way to find a written treatment: ask again for the
next room, and the next, across the catalog.

The refusal now names where the depth exists and says that reading it requires
nothing.

```text
study depth mathematics is unavailable for this room; it is written for lissajous so far, and reading it requires nothing
```

The App reader, the CLI, and MCP all say it. Study has never had a visit,
level, or progress requirement, so the pointer states that plainly rather than
leaving a reader to wonder whether something must first be earned.

Every study response also carries `authoredDepthRooms`, catalog-wide coverage
for the depths whose coverage is a real subset. A client can read which rooms
have an authored treatment without probing and without provoking an error.
Explanation and notes are deliberately absent from it: every room has both, so
listing rooms would restate the whole catalog. The field is additive to schema
version 1, and a reader that ignores it sees exactly the document it saw before.

Core owns the authored set, and one constant both selects the authored blocks
and answers what is advertised, so an advertisement cannot outlive its content.
A test walks all 355 rooms and requires the advertised set to equal the set that
actually has the depth. A second follows every advertisement and requires a real
answer, because advice that refuses in turn is worse than none.

## Counts read correctly when a count is one

A number written beside a fixed plural noun looks right for as long as the
number stays above one. Three readouts had passed that point. Entering any of
the two single-room wings announced `1 ROOMS`. The Journey overlay said
`1 PLAYS` after a first game, which every player reaches exactly once. Eight of
the 256 Only Move rulebooks count a single line and read `1 LINES`.

Core now owns one counted-noun helper and every readout calls it, so the rule
cannot disagree with itself across the faces. This is the class rather than the
three cases. The other counted readouts were checked: the engineered-aha rooms
hold their counts behind earn thresholds of four and eight, so their plurals
cannot be reached, and they were left alone rather than guarded against a case
no player can hit.

Each regression is written against live data instead of a count copied down
beside it, because a copied count is how this survived. The wing test walks the
real catalog and the Only Move test walks the eight single-line rulebooks.
