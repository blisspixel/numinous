# Numinous 0.5.0 alpha 3

The App's audio settings can now be inspected without a window or sound card.

Run `numinous settings` for Master, Radio, Room Sound, Effects, and mute, or
`numinous settings --json` for the same values with saved/default provenance.
The command uses the App's shared bounded preferences reader. Missing files
use first-run defaults; valid legacy files retain shared migration defaults;
damaged or unreadable files return an error. It changes no files and stays
independent of Journey and scores.

These values describe App launch preferences. They do not claim device
availability, observe a running mixer, or change pre-master sound exports.
The existing App Settings controls remain the place to change them.

Updating an unmarked loose archive remains refused to protect its contents.
The error now names the recovery: download a fresh archive or use the
installer with `NUMINOUS_HOME` set to a separate empty directory, keeping
the existing tree intact.

The prior packaged seals remain: unknown bare Studio names are refused,
zero-reading proofs have no melody, oversized optional audio keeps its notes,
and Mandelbrot keeps its continuous multicolor edge on a quiet ground.

Sensory Alpha remains active. General text scaling, physical pacing
qualification, native Overture playback, and Vibe remain on the roadmap.
Human playtests are optional feedback and do not gate this release.
