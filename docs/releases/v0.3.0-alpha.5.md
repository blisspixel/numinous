# Numinous 0.3.0 alpha 5

This prerelease gives every Studio face one shared interpretation of a plot or
melody request.

## What changed

- App, CLI, and MCP now use the same 32-note default melody.
- CLI and MCP text plots now share the same 72 by 26 default frame.
- Face-neutral `PlotRequest` and `SingRequest` types own expression parsing,
  discovery, defaults, bounds, and undefined-function refusals.
- The CLI no longer carries a separate plot sampler. It presents the result
  produced by the same headless core boundary as MCP.
- The old source-reading lock for the former 24, 32, and 48-note disagreement
  is gone. Typed core tests and real binary comparisons now prove the shared
  contract.

## Agent experience

A digital player can create a plot or melody through MCP with the same omitted
choices a human receives in the App or CLI. The protocol still returns bounded
structured notes and plot data, while the App can reconstruct a consented
public Studio action for a watcher. No model service, account, network
transport, or paid inference is required.

The creator-parity cohort now runs 12 plot and 10 melody comparisons through
the built CLI and MCP binaries. One case omits the note count in both faces and
proves that each produces the same 32-note phrase. The exact Formula Jam
tactile theorem continues to request its own 24-sample grid because that proof
depends on the grid, not on an interface default.

## Evidence

- Six focused request-boundary tests cover defaults, discovery, validation,
  source limits, undefined functions, and valid expression whitespace.
- Complete Core, App, CLI, and MCP package suites pass, including real MCP
  stdio sessions and native Watch Agent reconstruction.
- Creator parity passes 22 of 22 real binary comparisons.
- The full Windows release gate passed in 1,489 seconds: 3,518 passing
  all-target test cases, three expensive diagnostics intentionally ignored by
  the ordinary run, 95.09% region coverage, and 95.19% line coverage. Public
  CI remains required on the tagged commit.
