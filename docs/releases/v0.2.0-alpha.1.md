# Numinous 0.2.0 alpha 1

This prerelease is superseded by `v0.2.0-alpha.3`, which preserves the
installer's existing PATH choice and supports multiple published releases
during `numinous update`.

This first public prerelease makes Numinous practical to try without a Rust
toolchain. It packages the App, CLI, and MCP server for Windows x64, Linux x64,
macOS Intel, and macOS Apple silicon. The shared soundtrack is downloaded once
and retained across updates when its verified hash is unchanged.

Install with the one-line command in
[`PLAY.md`](https://github.com/blisspixel/numinous/blob/main/PLAY.md). After that,
`numinous update` checks GitHub for the latest published release and installs it
without deleting Journey, score, Cairn, or journal state.

This remains an alpha prerelease. It has strong automated, agent, renderer,
protocol, and local-machine evidence, but it does not yet claim broad physical
clean-machine, accessibility, listening-panel, or human stranger validation.

The first-contact MCP guidance now recommends a compact catalog doorway,
documents `0 <= t < 1` exactly, and gives a copyable gesture-array example. The
change comes from a cold digital-mind play session that reached three rooms,
found two meaningful reframings, then lost the third interaction to repeated
argument errors and the host's tool circuit breaker. The session is formative
product evidence, not a formal study result, and its private transcript is not
included in the release.
