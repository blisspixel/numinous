# Numinous 0.4.0 alpha 31

A clearer front door, random route maps, and a consistent visual language.

## Explore a route problem

Route Lab's Maps page offers reproducible random networks. Choose node count,
extra connections, and maximum road cost, then apply the displayed seed or
generate a new one. Core guarantees connected maps with distinct roads and
positive integer costs. Replacing a map is undoable and clears stale search;
an opened creation requires a deliberate remix first.

Shortest-path search has independent START and END controls. Pick either point
with the arrow buttons or directly on the map. RUN SEARCH records the calculation;
STEP and BACK reveal and revisit its decisions. The current recording keeps
its own endpoints when you change the next choices.

This point-to-point question sits beside the existing delivery round trip,
which chooses an order through required stops and returns to its depot.

The README now introduces Numinous, gets you playing, and explains Watch, Play,
and Create. Two representative screenshots replace the longer front-page
gallery. The full gallery lives in the visual guide; bundled Studio experiment
ids live in the Studio guide; Route Lab's screenshot and detailed controls live
in its own guide. Each is linked from the README.
Links to guides and images outside the archive point to the repository, so
downloaded players can reach them too.

## One visual language

Route Lab's native editor and thumbnails use the same teal accent as the room,
replacing their separate amber palette. Map labels and nodes also stay within
that accent instead of using an unrelated magenta. Search decisions remain
distinguishable through shape, brightness, dashed connections, and multiple
strokes.

Mandelbrot's CPU image keeps non-escaping samples on the shared near-black stage.
The exterior uses accent brightness bands, replacing its gray fill. The GPU
image already keeps that dark interior; the CPU screenshot is still a separate
escape-time rendering.

Existing solver algorithms, project formats, and saved creations remain
compatible. Random generation and endpoint controls use the existing workbench.
Understanding Alpha's exit remains open.
