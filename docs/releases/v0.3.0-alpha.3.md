# Numinous 0.3.0 alpha 3

Superseded by `v0.3.0-alpha.4`.

This prerelease gives Parrondo's Trap the sixth room-owned Universal Wager and
corrects the mathematics beneath the room.

## What changed

- Try a rule, then call A, B, or ABB in the App or through MCP
  `policy_wager`.
- Watch exact expected-capital paths for all three policies arrive before the
  answer is named.
- Meet typed 120-turn expectations and a graded sentence after consolidation.
- Observe without predicting by completing four policy selections.

The earlier room said strict ABAB was a winning alternation. For the room's
probabilities, exact Markov expectation shows that ABAB still loses. The
canonical combined policy is now ABB, which wins by changing how often game B
encounters the capital residue that selects its bad coin. Sampled walks remain
playable, but deterministic expectation owns the truth.

## Agent experience

The MCP server advertises `policy_wager` during discovery and returns the
policy options, wager, truth, correctness, exact expected ends, beat, earn,
reveal gate, and visual comparison in structured content. The local agent
hallway exercises a cold open, a fertile miss, and a correct consolidated call
through real MCP stdio for five fixed lenses. It uses no paid inference.
