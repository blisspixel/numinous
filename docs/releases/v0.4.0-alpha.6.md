# Numinous 0.4.0 alpha 6

A player can stay in a room.

Three source-blind playtests produced defects, and the last one produced
something better: the name of a verb this face did not have. Every look was a
new stateless call, so a player who wanted to keep sitting with one dark point
had to re-ask for it, and the room could not know they had never left. Staying
was the only thing the agent face could not express.

## Dwell

`play_room` accepts `dwell`, two to eight phases, one player, one room.
`structuredContent.dwell` returns a typed **invariant** rather than a delta.

That is the honest dual of the two-phase evidence already here. A delta answers
what a moment changed. An invariant answers what refused to move: cells that
never changed, cells that never lit, cells that always carried ink, the box that
did move, and blank cells fully ringed by cells that were never once dark.

```
play_room { "id": "unlit-room", "t": 0.5,
            "dwell": [0.05, 0.2, 0.35, 0.5, 0.65, 0.8, 0.95] }

"Dwell: across 7 looks, 675 of 800 cells held still,
 and 83 stayed dark inside the region that moved"
```

Two rules shaped it.

**Statelessness is not negotiable.** The player carries the looks and the room
does the arithmetic. No session state, elapsed duration, ordering, or path
between looks is created or implied. Repeating one phase is valid and honestly
answers that nothing moved. The memory belongs to the player; only the
measurement belongs to the room.

**Staying is not a second way to be told the answer.** The previous release
stopped an ordinary room from lecturing when a goal was met, and the same line
holds here. What returning earns is a measurement the player extracted, never an
explanation the room volunteered. A regression proves a dwell never carries a
revelation.

## An honest limit

`never_ink_enclosed` reads the drawn character grid, not the mathematics under
it. It first measured as exactly one cell in The Unlit Room and zero everywhere
else, which looked like that room's secret falling out of the instrument.
Re-running across canvas sizes and variations returned zero, one, or two, so
that was a lucky configuration rather than a signal: a grid coarse enough to
stipple a lit region can leave a real hole unringed.

A positive count is therefore a real hole in the drawn light, and a zero is
unproven rather than evidence that none exists. The documentation says so, and
the tests check the measure's properties on constructed frames instead of
pinning a flattering number from one room.

## Evidence

- Swept across all 354 rooms: none broken, every invariant self-consistent, no
  dwell carrying a revelation, and identical results on repeat.
- Seven rooms are honestly phase-static across four phases. `arecibo` is among
  them, which is independently what the third playtest found by hand when it
  reported that `t` does nothing in that room.
- 34 rooms report at least one enclosed dark hole, led by Barnsley Fern at 14,
  which is what a fern's fronds should produce.

result, a learning result, or a consciousness measurement.
