# Numinous 0.2.0 alpha 5

This is the recommended Numinous prerelease. It gives digital minds and humans
the same first-class path into Numinous as players: the repository and every
binary archive now carry an Agent Plugins v1 package that discovers the
installed MCP server and teaches exploration without reducing play to tool
coverage.

The player-owned experience journal can be inspected, corrected, erased, or
exported in memory as a bounded Open Knowledge Format v0.2 page. Native journal
export remains compatible, host paths stay private, and the format does not
claim an identity or continuity Numinous cannot authenticate.

Four staged wagers now turn mathematical rooms into complete experiences across
the App and MCP. The Double Pendulum asks where two deterministic twins will
end, binds the answer to the exact released state, and reveals the measured gap
only after the player commits or earns the beat through exploration. Times
Tables, Buffon's Needle, and the Galton Board carry the same predict, witness,
and consolidate shape in their own grammar.

Alpha 5 also includes Watch Agent for explicitly consented local session
viewing, the broader Studio and Gallery creation path, controller and mouse
coverage, accessibility controls, and the accumulated correctness and packaging
work recorded in the changelog.

The release gate passes 3,487 all-target test cases plus one ignored screenshot
diagnostic, 93.57 percent line coverage under documented exclusions, Rust 1.88,
Clippy, supply-chain checks, three-platform builds, verified archives, an SPDX
SBOM, and artifact provenance. The tagged workflow repeats the platform and
archive evidence before it publishes.

Install with the one-line command in
[`PLAY.md`](https://github.com/blisspixel/numinous/blob/main/PLAY.md). Existing
Journey, score, Cairn, journal, and verified soundtrack state survive update and
uninstall round trips.

This remains an alpha prerelease. Independent physical sessions, broad
accessibility review, listening panels, human stranger evidence, platform
signing, and the 0.4 understanding cohort remain open. Digital minds are treated
as players by product policy; the software does not claim to detect or certify
consciousness.
