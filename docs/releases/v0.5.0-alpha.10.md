# Numinous 0.5.0 alpha 10

Play is the same as alpha 9. This release records a contributor rule: an
issue carries a short closeout before it is finished. The note says what
changed or was decided, where it lives, and which checks passed, failed,
were blocked, or were not run. The checklist is in `AGENTS.md`.

The photosensitivity ceiling is `flash_budget_scale`. A previous name made
code scanning treat that speed as certificate data. The speed is unchanged.

Sensory Alpha remains active. Physical pacing receipts, the flash and
color-vision rulings, catalog-wide perceptual comparison, and further glow
stay open. This release does not claim the Sensory Lift is promoted.
Understanding Alpha's qualifying study remains open. Roadmap row 5 stays
open: Attention and Strange Loop are rebuilt, and the thin-room scorecard
and the commissioned cohort are not.

- [Start playing](https://github.com/blisspixel/numinous/blob/v0.5.0-alpha.10/PLAY.md)
- [Verify a build](https://github.com/blisspixel/numinous/blob/v0.5.0-alpha.10/VERIFY.md)

For an installer-created installation, run `numinous update`. For a loose
archive, download a fresh platform archive. Player-owned state is retained by
the managed update path.
