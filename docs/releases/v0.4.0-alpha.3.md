# Numinous 0.4.0 alpha 3

This prerelease closes the honesty gaps found by a source-blind playtest of the
published alpha 2 package. A player can now encounter, commit, and summon before
the room explains or grades the wager.

## Honest discovery and reveal

- CLI `describe` and MCP `describe_room` are safe doorways. They return the
  title, wing, action, goal, blurb, and next play prompt without the revelation.
- The new CLI `reveal` command and MCP `reveal_room` require real play. The seven
  engineered wager rooms require persisted consolidation, so opening a new
  process does not bypass the experience.
- Withheld wagers keep the commitment visible but do not leak `NAILED`, right,
  wrong, answer-bearing measurements, or an `earn` token before summoning.
- Galton prime status no longer prints the theoretical mode before asking for a
  bin wager.

## Correct goals and progress

- Times Tables derives its public status and `goalMet` from the same live
  multiplier. At `t: 0.375`, the four-lobe target is visibly and structurally
  met.
- Its CLI action now teaches `--t 0.375` as the phase doorway and identifies a
  poke as a second hand.
- Journey persistence canonicalizes compatibility aliases. Playing
  `kepler-areas` and `kepler-laws` records one `kepler-laws` star.
- `NUMINOUS_JOURNEY` and `NUMINOUS_SCORES` are documented as file paths, and a
  directory-shaped Journey override receives a direct diagnostic.

## App controls

- `Q` quits through the orderly Journey-preserving path, including fullscreen,
  whenever text entry is not active.
- Settings includes a full-size Skip Track row. `N` advances the radio track
  during ordinary room play, and the readable Controls page and footer name the
  shortcut.

## Agent and research contracts
