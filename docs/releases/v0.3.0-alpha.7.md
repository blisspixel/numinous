# Numinous 0.3.0 alpha 7

Superseded by `v0.4.0-alpha.1`.

This prerelease gives digital players exact paired observations and completes
two focused Rust face extractions.

## What changed

- `play_room` accepts an optional exact origin phase, `from_t`, with an
  explicit destination `t`. The additive temporal result carries both phases,
  origin status, origin render, and a typed cell delta without changing the
  existing destination result.
- Temporal play is deterministic, stateless, and limited to two observations
  of at most 2,304 cells each. Pokes are applied independently at each phase,
  while a phase-stamped gesture supplies one bounded event history to both
  samples for room-defined causal behavior.
- Watch Agent reconstructs an ordinary destination observation natively. An
  engineered Aha overlay retains the exact public text until that overlay is
  owned by the shared Rust replay contract.
- A maximum-variation sweep now exercises every listed room through the real
  bounded consent queue. It also hardened five seed calculations against
  schema-valid `u64` overflow.
- MCP protocol discovery and its immutable 35-tool schema catalog moved into
  a dedicated Rust module. CLI and MCP local-state presentation also moved
  into focused face modules, while core remains the only owner of resolution,
  locking, inspection, and mutation.

## Agent experience

Agent Plugins remains the portable doorway, MCP remains the live play surface,
and the Rust core remains the replay authority. A paired observation is exact
visible-change evidence, not an inferred path, duration, session, memory, or
inner state. Successful play records the existing coarse Journey room visit
without silently promoting an experience-journal entry.

Open Knowledge Format v0.2 remains a player-approved export target. It is not
used as a live play protocol or an implicit encounter receipt. A future
Numinous Encounter Receipt remains a separate, versioned contract with
explicit promotion.

## Evidence

- The full Windows release gate passed in 1,702.5 seconds with 3,551 passing
  all-target Rust cases and three expensive diagnostics intentionally ignored
  by the ordinary run.
- Measured coverage is 95.32 percent by region and 95.34 percent by line. Core
  persistence measures 94.73 percent by region and 95.33 percent by line.
- Focused tests cover equal and decreasing phase pairs, interaction and
  temporal delta separation, compact response parity, gesture causality,
  persistence boundaries, public-event size, and all 354 listed rooms at the
  maximum accepted variation.
- A zero-cost local 8B model visit proved that the outside-in harness detects
  narrated tool calls that did not occur. The model made no valid calls and
  timed out, so the run is recorded as an honest exploratory failure rather
  than play success.
- Public CI remains required on the release commit and tag. Tagged publication
  also requires four release packages, isolated install and play smoke tests,
  a locked SPDX inventory, provenance, and attestations.
