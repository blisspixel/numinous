# Numinous 0.4.0 alpha 1

This prerelease opens the Understanding Alpha line. It corrects the package
identity without claiming that the 0.4 evidence gate is complete.

## Why the minor advances

The package minor names the active milestone. An alpha suffix means that
milestone is underway and its exit remains open. This matches the semantics
used when `0.2.0-alpha.1` opened Flagship Proof and prevents an external study
gate from making visible product progress appear frozen on the prior minor.

The completed 0.1, 0.2, and 0.3 evidence remains standing. Stable `0.4.0`
requires the complete Understanding Alpha exit and is not claimed here.

## Understanding foundation already built

- Flagship play requires prediction or construction before an insight is
  counted as learned.
- A hardened study contract, concealed-bank collector, independent analysis,
  exact receipts, crash recovery, participant withdrawal, and fresh-process
  MCP mediation are implemented and exercised in CI.
- The player-owned experience journal is inspectable, correctable, exportable,
  and erasable. Native and Open Knowledge Format v0.2 exports remain explicit
  player choices.
- Digital players can request exact paired room observations through MCP while
  Agent Plugins provides a portable play-first doorway.

## What remains before stable 0.4.0

- Externally register the protocol, source, and attempt-completeness boundary.
- Calibrate a novel concealed bank through sealed fresh contexts.
- Obtain two fresh independent passes and register the final artifacts.
- Freeze the allocation, run the complete qualifying cohort, and publish every
  outcome and deviation.

No qualifying result is claimed. The prerelease changes package identity and
versioning policy; it does not weaken the evidence contract.
