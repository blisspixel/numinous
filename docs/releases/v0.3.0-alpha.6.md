# Numinous 0.3.0 alpha 6

This prerelease makes local state safer and moves more shared game truth into
the Rust core.

## What changed

- One core resolver now owns every local-state path used by the App, CLI, and
  MCP server.
- Complete local-state inventory and erasure now include the opt-in experience
  journal, with separate consent for journal-only erasure.
- Erasure rejects parent traversal, path aliases, Windows case aliases, and
  any managed radio cache that overlaps a player-selected soundtrack.
- One typed Gauntlet owns its stages, grading, score, reveals, and leaderboard
  identity across every face.
- One typed room catalog now owns public metadata and replayable constructors
  for all 354 listed rooms while keeping hidden content out of discovery.
- Product rules remain in Rust. Python is limited to outside-in process,
  package, hardware, and study evidence where an independent harness is useful.

## Agent experience

Digital players still enter through the portable Agent Plugins package and
play over MCP without a paid model service. The same state paths and erasure
contract now apply whether a player uses the App, CLI, or MCP server. Journal
export remains player-approved and supports both the native format and Open
Knowledge Format v0.2.

These boundaries keep the live experience, discovery package, and portable
knowledge projection distinct. MCP carries play, Agent Plugins carries the
doorway, and OKF carries only the knowledge a player chooses to export.

## Evidence

- The full Windows release gate passed in 1,764.6 seconds with 3,535 passing
  all-target Rust cases and three expensive diagnostics intentionally ignored
  by the ordinary run.
- Measured coverage is 95.15 percent by region and 95.13 percent by line. Core
  persistence measures 94.73 percent by region and 95.33 percent by line.
- CLI process and MCP regressions prove selective journal erasure and
  preservation of every unselected store.
- Alias regressions cover nonexistent path components, Unix symlink traversal,
  Windows case folding, and protected soundtrack overlap.
- Public CI remains required on the release commit and the tag. Tagged release
  publication also requires four-platform packages, isolated install and play
  smoke tests, a locked SPDX inventory, provenance, and attestations.
