# Numinous 0.5.0 alpha 5

Settings > Interface Text now saves Cabinet and room lettering at 100, 125,
or 150 percent of the window's own pixel scale. The same choice sizes the
room header and footer, the audio status, Show chrome, and the pause, banner,
and journey overlays. Each surface steps back down until titles, status, and
controls stay inside the window. One hundred percent keeps the scale those
surfaces already used, so the existing visual goldens stay in place.

Reading Text remains the separate study-body setting. Gallery, games, Studio,
and in-room pictures keep their own layout scales. Older preference files
keep their saved values and start Interface Text at 100 percent.

Sensory Alpha remains active. Physical pacing receipts, perceptual image and
spectral audio regression, and the remaining flash and color-vision decisions
stay open. This release does not claim the Sensory Lift is promoted.

archive, download a fresh platform archive. Player-owned state is retained by
the managed update path.
