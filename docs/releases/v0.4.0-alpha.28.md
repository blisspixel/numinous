# Numinous 0.4.0 alpha 28

Build a delivery network, ask a question, and keep the experiment for another visit.

## Route Lab

Choose a delivery order and compare its round-trip cost with nearest-neighbor
and the exact minimum. The street walk follows real roads. Close a road,
change its cost, undo a change, or step through recorded shortest-path decisions.
Unreachable deliveries stay visible with repair guidance.

Cabinet CONSTRUCT, or O in Route Lab, opens native authoring. Edit junctions,
roads, deliveries, the depot, and delivery order with pointer, keyboard, or
controller controls. Search playback uses the same solver as the comparisons.
The map is a schematic; the selected-road readout gives its cost.

## An experiment you can keep

A portable route capsule preserves the authored network and order. Keep it
with a question in the existing project chain. The Cabinet reopens that exact
network, and CLI or MCP previews supply a followable open or remix call.
Explicit remix records the source as its parent. Ordinary edits retain that
lineage. Reopening starts fresh undo and search playback.

CLI `route-lab` supports custom JSON networks and capsule export. Project
commands can keep a route, export or import a portable project revision, and
print JSON resume previews. MCP uses the existing `route_lab` and project tools.
Route-containing projects use version 2; existing Studio version 1 documents and identities
remain compatible.

## Polish and interoperability

Studio preserves undefined gaps and isolated points in its graph previews,
keeps long-formula cursors visible, and presents slope and partial readings
before navigation context. Room footers adapt to the available space.
Route Lab explains delivery order, street walk, and round-trip cost consistently
across its three faces.

Portable plugin validation checks pinned official schemas, real YAML parsing,
and production knowledge-export round trips. These are local conformance
checks; real-host discovery and participant usability evidence remain open.
Understanding Alpha remains active, with its exit awaiting the registered study.
