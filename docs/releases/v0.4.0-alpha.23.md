# Numinous 0.4.0 alpha 23

Documentation honesty, in the files a downloaded package actually carries.

## The Journey counters, explained where you can read them

An external playtest of the alpha 22 packages read the Journey play count
sitting at zero over the protocol face and reasonably concluded the field was
dead. It is not, and nothing in the package said so.

Entering a room lights a star. The play count records rounds played, sims run,
and curves made, so games, challenges, and Studio advance it while `play_room`
does not: rendering a room is deliberately stateless, and replaying the same
input returns the same result without recording anything. A session that only
renders rooms sees stars grow while plays stays at zero, by design.

Both facts now appear in `PLAY.md` and in the packaged agent skill.

## A promise that pointed at a file no player can open

The alpha 22 release note said the player manual documented that counter. The
sentence had been written into `docs/PLAYING.md`, which no release archive
carries. A downloaded package holds four readable documents: `PLAY.md`,
`README.md`, `VERIFY.md`, and the packaged skill. The alpha 22 note is corrected
to say where its sentence actually landed, and the engineering guide now names
the four documents a package carries, because the trap is invisible from inside
the repository where every file looks equally present.
