# Numinous 0.4.0 alpha 30

Share a route question and reopen its exact network in the native App.

## A question you can pass forward

Route Lab's Keep page offers SHARE beside KEEP QUESTION. SHARE exports the
chosen question, authored roads, closures, deliveries, depot, and order as one
portable `.project` file. Sharing does not add a local saved question. Each
export uses a new file and preserves the source creation's existing lineage.

Drop a route `.project` file into the App or pass its path when launching. The App
validates the bounded document and shows a paused preview. OPEN starts an
in-memory experiment; KEEP deliberately imports the question into the local
project chain. Leaving the preview restores the preceding editing session.
The local Gallery also discovers shared route questions beside Studio creations;
selecting a question opens the same paused receiving flow.

Received and kept question bands and Gallery captions use the bundled shaped
text renderer. Long questions expose paging controls, including PageUp and
PageDown on a keyboard. Sharing receipts preserve file-path case and Unicode
and provide the same bounded paging for long paths.
Dense network previews preserve roads while distinguishing the depot and
deliveries, and compact Gallery hints keep the back action visible.

The same document is usable through the existing CLI and MCP project tools.
Route-containing documents keep their version 2 format. Existing Studio
version 1 documents remain compatible with the project tools; native file
receiving in this release accepts route projects. Questions stay data and do
not execute commands. OPEN opens the embedded route, and KEEP retains its
original closed next call without executing it.

## Scope and evidence

Core owns document validation, identity, preview, and persistence. Native
input and composed-frame regressions cover the receiving flow, and real
transport tests follow the portable route's next call. These are functional
and rendering checks. Participant comprehension remains unmeasured, and
Understanding Alpha's exit remains open.
