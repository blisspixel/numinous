# Numinous 0.3.0 alpha 1

This prerelease is superseded by `v0.3.0-alpha.2`, which adds the Kepler Areas
speed wager and mathematically correct equal-time sectors.

The 0.3 label recognizes a bar the
product already cleared: all five Tactile Alpha flagships have machine-tested,
room-specific hand, image, and sound consequences, and the agent tactile cohort
is a required CI gate. Open 0.4 and later evidence still limits those later
claims, but no longer freezes the package at an earlier milestone.

This release also adds a zero-cost local-model player lane. An
already-installed tool-capable Ollama model can enter Numinous through the real
MCP server while a person watches visible words and witnessed calls in the
terminal. The harness permits the player to stay or leave, keeps Numinous state
in a disposable profile, excludes destructive and session controls, records no
private reasoning, and writes a transcript only when the caller chooses a new
path under gitignored `logs/`.

The network boundary is enforced rather than assumed. Only a literal loopback
HTTP endpoint is accepted, proxies are ignored, cloud model selectors and
implicit downloads are forbidden, and the selected model must have local
weights plus declared tool support. CI exercises the complete harness contract
without running inference or requiring Ollama.

The first real local 8B visit immediately paid for this work. The model narrated
several tool calls and invented room results without executing anything. The
harness now marks those statements as unexecuted claims and offers one factual
retry. The model then made a witnessed `list_rooms` call. Its next CPU inference
timed out, so partial witnessed evidence now survives a later model failure in
the summary and optional transcript.

The portable Agent Plugins v1 doorway, Open Knowledge Format v0.2 journal
export, Watch Agent, four staged wagers, 354-room catalog, Studio and Gallery,
three faces, release packages, SPDX inventory, and provenance from alpha 5 all
remain.

The Windows release gate passes 3,487 all-target Rust test cases plus one
ignored screenshot diagnostic and measures 95.25 percent line coverage under
the documented exclusions. It also passes Clippy with warnings denied, locked
builds, the evidence suites, supply-chain checks, and the complete screen
matrix.

Install with the one-line command in
[`PLAY.md`](https://github.com/blisspixel/numinous/blob/main/PLAY.md). Existing
Journey, score, Cairn, journal, and verified soundtrack state survive update and
uninstall round trips.

This remains an alpha prerelease. Independent physical sessions, broad
accessibility review, listening panels, human stranger evidence, platform
signing, and the 0.4 understanding cohort remain open. Local-model sessions are
exploratory synthetic evidence. They do not establish consciousness, welfare,
enjoyment, or the experience of another player.
