# Numinous 0.5.0 alpha 7

Linux first-run now names the window `com.blisspixel.numinous` on Wayland and
X11, and the desktop entry uses that same StartupWMClass. The installer writes
the bash PATH line to `.bashrc`, and to `.profile` only when `.bash_profile`
is absent. Source builds document the pkg-config, compiler, ALSA, xkbcommon,
and libudev packages the installer already checks. `numinous render --out`
defaults to 1024x1024 when width and height are omitted. ASCII rendering stays
80x40. The menu help footer keeps its group spacing.

Appending private state or a diagnostic log refuses a symlink, so the append
does not change the link's target or its permissions. Replacing a state file
through a symlink leaves the target intact and writes a regular file at the
state path. An old GitHub CLI that cannot run `gh attestation verify` with
`--source-digest`, `--signer-digest`, and `--deny-self-hosted-runners` is
named as outdated. Those flags stay required.

Non-finite audio stays rejected: a non-finite sample is silence, a non-finite
frequency is not a pitch, and an overflowing interval is not an octave.
Flagship peak, RMS, PNG-mean, fingerprint, and luminance checks reject a
non-finite value. The supply-chain job installs cargo-deny 0.20.2 and runs
the same check without pulling a Rust image from Docker Hub.

Sensory Alpha remains active. Physical pacing receipts, the flash and
color-vision rulings, catalog-wide perceptual comparison, and further glow
stay open. This release does not claim the Sensory Lift is promoted.
