# Numinous 0.5.0 alpha 11

Play is the same as alpha 10. The CLI HTTP client, used for the
published-release check and for music requests, rejects distrusted emSign
intermediates and no longer bundles the emSign ECC Root CA - G3
(RUSTSEC-2026-0382 and RUSTSEC-2026-0381). `ureq` stays 3.4.1.

On Windows, a managed Installed Apps entry whose install directory is gone
can be claimed by a new install. An entry for a different install that is
still on disk is left alone. The uninstall roundtrip saves that registration
and writes it back, because the key is in HKCU and an overridden profile
does not move it. `numinous uninstall` already returns before its helper
finishes. The roundtrip waits for that process to exit, still within 10
seconds, and still requires the helper sentence.

Sensory Alpha remains active. Physical pacing receipts, the flash and
color-vision rulings, catalog-wide perceptual comparison, and further glow
stay open. This release does not claim the Sensory Lift is promoted.
Understanding Alpha's qualifying study remains open. Roadmap row 5 stays
open: Attention and Strange Loop are rebuilt, and the thin-room scorecard
and the commissioned cohort are not.

archive, download a fresh platform archive. Player-owned state is retained by
the managed update path.
