# Numinous 0.4.0 alpha 2

This prerelease makes the Understanding Alpha line easier to enter, easier to
play, and more honest about what a player has actually learned.

## Text-first Cabinet

- The App preserves its original opaque text screen and live power console.
- The former long flat index is divided into Modes, Games, Settings, and
  Controls. No selectable page has more than six rows.
- Large console-scale type, a fixed arrow cursor, keyboard shortcuts, pointer
  rows, and controller navigation share one typed state and geometry model.
- Desktop type scales in whole pixel steps with the viewport, from the title
  and choices through the descriptions, Controls page, and command legend.
  A dedicated wide 7 by 7 cartridge face keeps the Cabinet distinct from the
  compact room HUD. The fullscreen legend names `F EXIT FULLSCREEN`, and `F`
  returns directly to windowed mode.
- A large `QUIT` row closes through the normal Journey-preserving shutdown
  path. It has no single-letter shortcut, and the legend also names `Alt+F4`.
- Activity pause is nondestructive. It exposes Resume, Restart only where the
  action is truthful, Controls, Settings, and Leave.
- Volume, mute, Visual Era, and window mode persist in a strict, bounded,
  versioned preference file. Complete local erasure inventories and removes
  it; selective erasure preserves it.

## Better play and discovery

- Engineered Aha answers stay absent until consolidation across all seven
  flagship learning loops. The wager remains visible while the answer stays
  closed.
- `kepler-areas` resolves as a compatibility alias for `kepler-laws` and all
  public results return the canonical identity.
- Compact MCP discovery names a small starter set instead of requiring a new
  player to inspect the whole catalog first.
- The POSIX installer handles an unset `SHELL` without failing under strict
  shell settings.

## Agent experience

- MCP can return two exact room observations and a typed visible-change delta
  in one bounded call without pretending that the interval was experienced.
- Independent pokes and causal phase-stamped gestures are distinguished in the
  public contract, portable Agent Plugin skill, and real stdio coverage.
- A consented Shared Play viewer accepts the paired evidence and reconstructs
  the destination frame locally.
- The experience journal remains inspectable, correctable, exportable in
  native or Open Knowledge Format v0.2 form, and explicitly erasable.

## Release boundary

Stable `0.4.0` still requires the complete Understanding Alpha evidence gate.
This prerelease does not claim a qualifying cohort result or consciousness
measurement. It advances the playable artifact while keeping those claims
bounded.

## Release evidence

- The complete Windows gate passes 3,563 all-target Rust cases, with three
  expensive diagnostics ignored by the ordinary suite. Measured coverage is
  95.27 percent by region and 95.27 percent by line under the documented
  hardware and event-loop exclusions.
- All 2,913 deterministic App screens pass the rendered QA matrix.
- Warning-denied Clippy, formatting, documentation, house style, installer
  self-tests, Agent Plugin validation, coverage, packaging, provenance, and
  three-operating-system CI remain required by the publication workflow.
