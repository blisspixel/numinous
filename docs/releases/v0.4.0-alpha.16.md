# Numinous 0.4.0 alpha 16

Formula Jam can draw one path with two coordinates, then make its y coordinate
the voice.

Type this in the App:

```text
x(t)=cos(3*t); y(t)=sin(2*t)
```

The result is one bounded program, not two unrelated graphs. Numinous samples
both coordinates over the same time window, finds finite planar bounds, and
draws the resulting Lissajous path. Undefined samples break the path instead
of joining across the gap. The App, CLI, and MCP use the same core program and
rendering contract.

## A path that can sing in a scale

A parametric creation sings its `y(t)` coordinate. Every Studio voice can now
use one of five pitch maps:

```text
continuous
chromatic
major
minor
pentatonic
```

F6 cycles the map in the App and immediately restarts the voice. The CLI and
MCP expose the same names. Continuous preserves the existing melody behavior;
the other choices quantize the same two-octave span to their pitch classes.
When MCP returns a receipt for `sing_expression`, its replay action includes
the selected map.

## One portable version 3 capsule

`NUMINOUS_STUDIO 3` carries the creation kind, exact pair, time window, knob,
and pitch map. The native link carries the same information. Save, paused
reopen, Gallery thumbnail, postcard, and fork all preserve it. Replacing a
parametric program requires both coordinates, so a half-edited pair cannot
silently borrow the other half from its parent.

Compatibility remains deliberate. A plain graph still writes version 1.
Identity, era, or lineage alone still writes version 2. Existing version 1 and
2 files and links retain their original bytes and behavior. Version 3 appears
only when a parametric pair or a non-continuous pitch map needs it.

## Three faces, one measured result

The CLI accepts paired `--x-expr` and `--y-expr` fields with optional `--tmin`
and `--tmax`. MCP uses the corresponding `x_expr`, `y_expr`, `tmin`, and `tmax`
fields. Both refuse a partial pair, a pair mixed with a graph expression, or a
pair mixed with graph discovery. The App editor keeps its last valid program
while an edit is incomplete, but will not share the incomplete text.

The creator roundtrip gate passes 11 checks, including deterministic version 3
serialization, exact reopen, stored-scale audio identity, atomic fork, and
partial-pair refusal. The creator parity gate passes 34 real CLI and MCP
comparisons: 20 drawings and 14 synthesized voices, including three parametric
paths and all four quantized pitch maps.

This release does not add arbitrary code, named sliders, a general number of
expressions, an independent second variable, MIDI or audio export commands, or
a qualifying Understanding Alpha cohort result. Stable 0.4.0 still requires
the registered study and independent audit named in the roadmap.
