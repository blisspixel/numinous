# Numinous 0.5.0 alpha 12

The Overture uses the existing full-resolution fractal GPU renderer when
available. Mandelbrot keeps the visible zoom when you take control, and
choosing the Times Tables experiment releases the score without resetting
the dial or replacing its music bed. Old celebration banners no longer cover
the opening. The adaptive software renderer remains available.

The locked cryptographic dependency uses ctutils 0.4.4, resolving
RUSTSEC-2026-0385. This dependency advisory does not establish an exploitable
App timing leak. Update App and MCP together: their exact build fingerprints
must match. Windows qualification tooling now distinguishes missing registry
keys without parsing localized text and verifies restoration of original
typed values and subkeys. Its integration tests use disposable keys.

Repository handoff rules now account for unfinished work at session start.
One optional Route Lab return-and-revise research pilot is specified as
Designed. No participant study has run, and no enjoyment or learning outcome
is claimed.

Sensory Alpha remains active. The GPU post stack stays disabled by default
pending its closed physical Windows, macOS, and native Linux timing set at
one frozen revision. The three capped rooms retain their 4x safety ceiling.
Understanding Alpha's qualifying study and Vibe remain open. Automated
frames and hosted runtime checks do not certify native listening comfort,
screen-reader support, or subjective visual improvement.
